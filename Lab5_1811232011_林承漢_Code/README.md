# Lab5 1811232011 林承漢

## Installation

- MacOS / Linux:

```bash
python -m venv .venv
source ./.venv/bin/activate

## Normal
pip install -r requirements.txt
## Using CUDA
pip install -r requirements_CUDA.txt
```

- Windows

```bash
python -m venv .venv
.\.venv\Scripts\activate.bat

## Normal
pip install -r requirements.txt
## Using CUDA
pip install -r requirements_CUDA.txt
```
